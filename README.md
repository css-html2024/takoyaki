# takoyaki

A bot program on the internet, aimed to act/mimic like a typical internet user.

## Usage
This project is create for personal use and was not designed for other's use. However, you may try to modify this project (with the assist of AI if you need XD)

**In Debian-based Distros** \
Change your directory to this project, and enter:
```
$ bash start_bot.sh
```
